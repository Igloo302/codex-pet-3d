# Codex Pet 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the complete `codex-pet-3d` monorepo containing specification schemas, glTF-transform asset inspection, cross-platform Three.js core runtime, headless 2D spritesheet baking, Web inspector, and an Electron transparent desktop floating companion.

**Architecture:** Monorepo with pnpm workspaces. `packages/spec` defines JSON Schema and TypeScript interfaces. `packages/core` wraps Three.js for loading GLB, skeletal animation state transitions, and LookAt tracking. `packages/cli` provides validation, preview, and 2D spritesheet baking. `packages/web` provides interactive web inspection. `packages/desktop` provides an Electron transparent desktop window running `@codex-pet-3d/core`.

**Tech Stack:** TypeScript, pnpm workspace, Node.js 20+, Three.js, @gltf-transform/core, Puppeteer (headless Chromium with SwiftShader), Vite, React, Tailwind CSS, Commander, Sharp, Electron.

**Spec:** [`docs/superpowers/specs/2026-11-09-codex-pet-3d-design.md`](file:///Users/jyshen/Projects/codex-pet-3d/docs/superpowers/specs/2026-11-09-codex-pet-3d-design.md)

## Global Constraints

- **Platform Support:** Node.js ≥ 20 on macOS, Linux, and Windows (verified via GitHub Actions matrix).
- **3D Asset Format:** Single-file `.glb` (glTF 2.0 binary, plain geometry and PBR materials, no Draco/KTX2 compression).
- **Polycount Budget:** Warning if triangles > 10,000; hard error if vertices > 25,000 (calculated by unique position accessors).
- **Texture Budget:** Max single texture resolution ≤ 1024×1024 (checked from image headers in bufferViews).
- **File Size Budget:** Max `.glb` size ≤ 5 MB.
- **Animation Clips:** Must cover 9 standard states (`idle`, `running-right`, `running-left`, `waving`, `jumping`, `failed`, `waiting`, `running`, `review`).
- **2D Baking Output:** Strict v2 grid format: 1536×2288 WebP, 8 columns × 11 rows (rows 0–8 actions, rows 9–10 16-direction clockwise look tracking). Unused cells must have `alpha === 0`.
- **API Portability:** Core parsing and model inspection accept `Uint8Array` / `ArrayBuffer` (no Node `Buffer` coupling) for browser Dropzone and Electron renderer portability.

## Review Focus

1. **Missing Animation Clip in GLB:** When a `.glb` is missing one or more of the 9 required animation clips, `validate` must return exit code 1, reporting code `MISSING_CLIPS` with the exact names of missing clips. (Tested in Task 5)
2. **Invalid Manifest Schema & Property Paths:** When `pet-3d.json` contains invalid fields, missing required properties, or out-of-range yaw/pitch degrees, validation must report structured `{ path, code, message }` errors. (Tested in Task 1)
3. **Empty or Truncated GLB File:** When passed a 0-byte or truncated `.glb` buffer (derived in-test via `.slice()`), `validate` and `bake-2d` must fail with `GlbFormatError` (code `GLB_TRUNCATED` or `GLB_INVALID_MAGIC`). (Tested in Task 2 & Task 5)
4. **2D Spritesheet Dimensions & Grid Alignment:** The `bake-2d` command must emit an exact 1536×2288 WebP image, verified by RIFF/WEBP header bytes, and unused cells (e.g. Row 0 Col 7) must have alpha=0. (Tested in Task 6)
5. **Headless Offscreen Context for Baking:** On headless environments without a display server, rendering must succeed without WebGL context initialization errors via Puppeteer SwiftShader software rendering. (Tested in Task 3)

import { resolve } from "node:path";

import sharp from "sharp";

describe("CLI bake-2d", () => {
  const sampleDir = resolve(__dirname, "../../../assets/cyber-cat");
  const outDir = resolve(__dirname, "temp-bake-output");

  afterAll(() => {

  it("bakes a compliant 1536x2288 WebP spritesheet with transparent unused cells", async () => {
    const result = await runBake2D(sampleDir, { out: outDir });
    expect(result.exitCode).toBe(0);

    const spritesheetPath = resolve(outDir, "spritesheet.webp");
    const buffer = readFileSync(spritesheetPath);

    // Verify WebP RIFF header bytes
    expect(buffer.subarray(0, 4).toString("ascii")).toBe("RIFF");
    expect(buffer.subarray(8, 12).toString("ascii")).toBe("WEBP");

    const image = sharp(buffer);
    const metadata = await image.metadata();
    expect(metadata.width).toBe(1536);
    expect(metadata.height).toBe(2288);

    // Verify unused cell (Row 0 Col 7: x = 7 * 192 + 96, y = 0 * 208 + 104) is alpha = 0
